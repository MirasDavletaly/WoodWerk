# Инструменты перевода

Скрипты, которыми собраны словари в `assets/i18n/`. Для работы сайта они
не нужны — нужны, когда меняется текст на страницах.

## Как пользоваться

Запускать из корня проекта.

```bash
python tools/i18n/extract.py check   # проверка: страницы пересобираются побайтово
python tools/i18n/extract.py apply   # расставить data-i18n и обновить ru.json
python tools/i18n/build.py           # показать, что осталось без перевода
python tools/i18n/build.py write     # собрать kk.json и en.json
```

`extract.py` идемпотентен: повторный запуск не задваивает разметку.
Перед `apply` он всегда проверяет, что умеет собрать страницу обратно
байт в байт — если нет, изменения не применяются.

## Где лежат переводы

`tr_part1.py` … `tr_part4.py` — тройки «русский оригинал, қазақша, English».
Сопоставление с разметкой идёт по русскому тексту, а не по ключу: ключи —
это хеши, они меняются при любой правке, а текст читаем и стабилен.

Чтобы добавить перевод, допишите тройку в любой из файлов и запустите
`build.py write`.
